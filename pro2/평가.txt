<4번>

제어문에서 반복을 처리할 때는 for와 while문이 있다. while은 일반 자료형의 반복을 처리할 때 사용하고 for는 묶음형 자료(list, set, tuple)을 처리할 때 사용한다.

함수란 객체지향적인 프로그램에서 자원의 재활용을 위해서 앞에서 자주사용하는 코드를 하나로 묶어 정리한 것을 말한다. 
함수의 형태는
def 함수명(가인수):
       실행문
        return 값
함수명(실인수)
의 형태이다. 여기서 가인수와 실인수는 같은 type의 자료여야하고 return값은 적혀있지 않으면 None을 반환한다.
함수를 시행할 때 'print(함수명()) vs print(함수)'에는 큰 차이가 있다. 결국 함수도 메모리에서 주소를 참조하게 된다. 단순히 '함수'만 print하게 되면 함수의 주소가 출력되고 함수명()을 하게되면 함수를 수행한 return값을 반환하게 된다.

함수를 이용한 반복 처리에는 Recursive Fucntion이 존재한다. 이 함수는 진행과정에 있어서 내려갈 때는 연산하지 않고 역으로 다시 올라오면서 연산처리를 한다.

<7번>

원래 하나의 변수는 하나의 값만 받을 수 있다. 하지만
위에서처럼 3개의 변수가 나란히 있으면서 set집합의 값을 받을 수 있다.
그때 v1의 변수에 *을 써주면 그 변수는 v2와 v3가 각각 하나의 값만 취하고 남은 나머지 객체들에 대해서 리스트 형태로 하나의 값을 받을 수 있다.
그러면 저기서 v2 = 4, v3 = 5를 받고 v1이 나머지를 받을까?
그건 아니다. 보면 집합형 자료가 set으로 표현되어 있다. set은 중복자료를 가질 수 없기에 저 코드는 
*v1, v2, v3 = {1,2,3,4,5} 로 고칠 수 있다.
다시 여기서 v2는 4, v3는 5를 가지고 *v1은 [1,2,3]을 가지게 된다.

class Bicycle:

    def __init__(self, name, wheel, price):
        self.name = name
        self.wheel = wheel
        self.price = price

    def display(self):
        cost = self.wheel * self.price
        print(f"{self.name}님 자전거 바퀴 가격 총액은 {cost}원 입니다.")
         
gildong = Bicycle('길동', 2, 50000)
